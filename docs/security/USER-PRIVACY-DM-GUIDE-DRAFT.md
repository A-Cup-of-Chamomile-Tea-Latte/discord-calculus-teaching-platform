# Discord 使用與私訊隱私指南（學生版草稿）

> 這是待教學團隊審核的草稿，不是已發布的校方政策。Discord 介面名稱可能更動，發布前應再用當時版本核對。

## 加入前先知道

1. 課程伺服器中的 `nnmmm` 暱稱只是這個伺服器的顯示名稱。它不會隱藏你的 Discord 全域 username、display name、頭像、個人檔案或你主動顯示的連結。
2. 「對一般成員匿名」不是對系統的完全匿名。為了防止冒用與處理濫用，只有經授權的管理人員可能透過受限記錄追溯作者；普通成員不應看到對照。
3. 「作者顯示」、「訊息可見範圍」與「是否允許教學分析」是三個不同的選擇。匿名發文不等於 Private Support，也不自動等於排除分析。
4. 作業、成績、期限與正式公告以 NTU COOL 為準。Discord/Portal 是補充工具。

## 降低陌生私訊與個資暴露

### 1. 關閉同伺服器陌生私訊

在 Discord 的使用者或伺服器隱私設定中，找到「允許來自同一伺服器成員的私人訊息」或同義選項，建議對課程伺服器關閉。你仍可主動加入信任的好友，或在需要時調整特定伺服器的設定。

### 2. 檢查全域個人檔案

- 使用不含學號、真實全名、班級或生日的 display name，除非你確實想公開。
- 檢查頭像、個人簡介與已連結帳號是否可用來交叉識別你。
- 更改全域 profile 可能影響其他伺服器；確認預覽後再儲存。

### 3. 縮小好友邀請範圍

若 Discord 提供「同伺服器成員可傳送好友邀請」的開關，可根據個人需要關閉或縮小範圍。

## 收到可疑 DM 怎麼做

- 不要回傳密碼、Discord token、OAuth code、email 驗證碼、啟動碼、學號、身分證件或私密作業資料。
- 教學團隊不應透過陌生 DM 要求你交出密碼、token 或驗證碼。若對方自稱教授／TA，請從 NTU COOL 的正式公告或課程已驗證管道另行確認。
- 不要點擊來路不明的連結或開啟附件。案件編號不是密碼，不要用它當作身分證明。
- 使用 Discord 的 block/report 功能，並保留發件帳號、時間與必要截圖。不要為了截圖繼續與對方互動。
- 由教學團隊發布正式聯絡管道後，將證據交給該管道；不要在公開頻道貼出可疑訊息中的個資或 token。

## 發問時的隱私選擇

### 一般案件

- 不要在標題或內容放學號、聯絡方式、成績、健康、家庭或其他不必要的敏感資料。
- 一般案件編號可能用於查詢進度，不要把它與額外個資一起公開分享。
- 完全匿名回覆必須由網站表單或 Discord modal 私下收集，再由 bot 代貼。不要先用自己帳號發文再刪除；notification、cache 或 audit 可能已暴露。

### Private Support

- Private Support 使用獨立入口，不產生公開案件編號，預設排除教學分析。
- 它不是緊急服務。若有立即安全或醫療需求，請使用當地的緊急協助管道，不要等待 Discord/Portal 回覆。
- 正式 Private Support mechanism 尚未啟用前，不要把真實敏感內容輸入 fixture 原型。

## 教學分析與撤回

- 教學分析同意不會改變你是否可以獲得回覆，也不等於公開發布、模型訓練或學生評分。
- 一般討論在明確匯出後，仍必須依 account 預設、逐篇 override、去識別化與人工複核規則處理。
- 正式的撤回、已匯出資料重處理與刪除流程尚待教學團隊核准；在最終政策公布前，原型不會自動將訊息送往 AI。

## 帳號或資料可能泄漏時

1. 先更改 Discord 密碼、登出其他階段並啟用雙因素驗證（若可用）。
2. 若曾交出 email/activation code，告知課程指定管道請求作廢；不要在公開頻道重貼該 code。
3. 記錄大約時間、影響功能與是否曾點擊連結；只透過教學團隊宣布的正式管道通報。
4. 不要自行刪除所有證據；先保留最小必要截圖供調查，但不要繼續轉傳敏感內容。
