# Forum 標籤

> 由 `python -m tools.config_proposal generate` 自動產生。請修改 `config/proposed/`，不要直接編輯本檔。
> 每篇案件只有一個 main tag 進入標題。

- **Math Questions**：觀念、計算、技巧、討論、其他
- **Coursework / Systems**：WeBWorK、Gradescope、NTU COOL、Quiz / Assessment、教材勘誤、學分 / 報名、其他
- **Other Problem / Free Talk**：討論、趣味題、課外延伸、其他
- **course-materials**：講義、題目、工具、參考資料、其他

最終 main tag 清單與同義詞策略仍需人工核准；目前清單用於本機展示與驗證。
