# 學生快速指南（草案）

> 這是原型的學生文案草案，尚未代表課程正式政策或機構核准。目前 Portal 使用虛構 fixtures，表單不會真正送出。

## 我要去哪裡？

- **教材、作業、成績、截止日、正式公告或課程政策**：以 NTU COOL 為準。
- **一般問題與討論**：可直接在 Discord 發問。
- **不想打開 Discord 發文**：未來可選擇由 Portal 代送；這是替代路徑，不是必經流程。
- **敏感、只希望教學團隊處理的求助**：使用 Private Support，不要用一般公開案件。

## 發問前請分開三個選擇

1. **作者顯示**：真名、課程代號 `nnmmm`、或對一般成員匿名。
2. **誰看得到**：班級、整門課、或只限教學團隊。
3. **教學分析同意**：內容能否在明確匯出、去識別化與人工複核後，用於課程品質檢視。這不等於公開、模型訓練或自動評分。

## Discord 隱私提醒

- 伺服器暱稱 `nnmmm` **不會**隱藏你的 Discord 全域 username、display name、avatar 或 profile。
- 建議在 Discord 隱私設定中，停用來自 shared-server members 的 unsolicited direct messages，並根據需要調整 friend request 設定。
- 完全匿名的回覆不可用「先以本人帳號發文、再立即刪除」。要使用網站或 Discord modal，由 bot 代貼。
- 對一般成員匿名不等於對授權管理者也無法識別。

## 案件編號與狀態

一般案件可取得類似 `C01-7K4M2Q-0702-1000` 的案件編號，並在 Portal 按需查詢狀態。Private Support 沒有公開查詢編號；公開查詢找不到時，不代表可以判斷私密案件存在與否。

狀態的意義：

- `OPEN`：等待教學團隊或下一步處理。
- `WAITING_FOR_STUDENT`：等待學生補充。
- `ANSWERED`：已有回覆。
- `ESCALATED`：已升級給指定教學人員。
- `CLOSED`：案件已結束。

## 系統無法使用時

- 正式課務資訊回 NTU COOL 確認。
- 一般問題使用課程已公告的 Discord 或備援管道；原型沒有提供正式 server link。
- Private Support 使用課程已公告的受保護連絡方式，不要把敏感內容改貼到公開討論區。
- 不要把 token、密碼、驗證碼或身分證明資料貼進問題內容。
