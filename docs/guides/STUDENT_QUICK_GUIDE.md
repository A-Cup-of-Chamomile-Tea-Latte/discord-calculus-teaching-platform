# 學生快速指南（草案）

> 這是 v13 deployment 上線前的學生文案草案，尚未代表課程正式政策或機構核准。Portal 的加入申請與
> 案件狀態 API 已在候選版完成，但尚未部署 production。

## 我要去哪裡？

- **教材、作業、成績、截止日、正式公告或課程政策**：以 NTU COOL 為準。
- **一般問題與討論**：可直接在 Discord 發問。
- **加入伺服器或查案件狀態**：使用 Portal；Portal 不代收題目、正文或附件。
- **敏感、只希望教學團隊處理的求助**：使用 Private Support，不要用一般公開案件。

Email 只用於加入申請時的一次性地址驗證。Private Support 的成立與重新開啟通知留在 Discord
DM，不把敏感案件案號、標題或連結另外寄到信箱。

## 發問前請分開三個選擇

1. **作者顯示**：真名、課程代號 `nnmmm`、或對一般成員匿名。
2. **誰看得到**：班級、整門課、或只限教學團隊。
3. **教學分析同意**：內容能否在明確匯出、去識別化與人工複核後，用於課程品質檢視。這不等於公開、模型訓練或自動評分。

## Discord 隱私提醒

- 伺服器暱稱 `nnmmm` **不會**隱藏你的 Discord 全域 username、display name、avatar 或 profile。
- 建議在 Discord 隱私設定中，停用來自 shared-server members 的 unsolicited direct messages，並根據需要調整 friend request 設定。
- 完全匿名的回覆不可用「先以本人帳號發文、再立即刪除」。要使用網站或 Discord modal，由 bot 代貼。
- 對一般成員匿名不等於對授權管理者也無法識別。

## 案件編號與狀態

一般學生案件會取得類似 `C01-7K4M2Q-0702-1000` 的案號；訪客案件使用
`Guest-7K4M2Q-0702-1000`，Private Support 則使用 `C99…-P`。三者都可在 Portal
依完整案號查最小狀態；題目、對話、作者與附件仍只能回授權的 Discord 空間查看。

狀態的意義：

- `OPEN`（新案件）：等待教學團隊接手。
- `TRACKED`（進行中）：教學團隊正在處理。
- `IDLE`（等待回覆）：教學團隊回覆後 48 小時沒有收到你的回應，系統已寄出提醒。
- `CLOSED`（已結案）：負責人已手動結案。
- `AUTO_CLOSED`（已自動結案）：提醒後再 48 小時仍沒有回應，系統已自動結案。

一般案件若之後繼續回覆，系統會沿用原案號與討論串，並把案件帶回「進行中」。Private
Support 在第二個 48 小時屆滿後，或手動結案滿 48 小時後，會先完成受控匯出驗證，再自動刪除受限頻道；若之後仍需協助，
教學團隊會建立新的 replacement case。匯出失敗時不會刪除頻道，而會交由系統管理員處理。

## 系統無法使用時

- 正式課務資訊回 NTU COOL 確認。
- 一般問題使用課程已公告的 Discord 或備援管道；原型沒有提供正式 server link。
- Private Support 使用課程已公告的受保護連絡方式，不要把敏感內容改貼到公開討論區。
- 不要把 token、密碼、驗證碼或身分證明資料貼進問題內容。
