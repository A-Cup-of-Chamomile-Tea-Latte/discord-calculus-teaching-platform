# Portal 舊版路由封存說明

封存日期：2026-08-24

這個 stage 保存架構調整前的設計意圖與替代關係。舊路由暫時留在 reviewer build 供追溯，但公開 artifact 會移除，避免舊流程與現行設計同時出現在學生面前。

| 舊路由                 | 封存原因                         | 現行入口                              |
| ---------------------- | -------------------------------- | ------------------------------------- |
| `/ask/`                | 網頁不再承擔提問與附件上傳       | Discord 公開討論區                    |
| `/private-support/`    | 隱密案件改由 Discord 指令建立    | Discord `/private-support`            |
| `/discord-guide/`      | 與使用／隱私指南重複             | `/guide/`                             |
| `/cases/[caseNumber]/` | 網頁不再顯示題目、對話或回覆內容 | `/cases/` 只查狀態，再回 Discord 閱讀 |
| `/status/`             | 建造清單與監控資訊為專案管理用途 | reviewer build 的管理員頁面           |

## 維護規則

- 封存資料不作為新功能或文案的依據。
- 公開 build 不得包含封存路由、內部登入程式或案件內容。
- 需要恢復舊設計時，先在決策紀錄說明原因，再將必要部分移回現行架構；不要直接複製整頁。
- 確認新流程穩定後，舊頁面可以再移出 Astro 路由樹，但仍保留於版本歷史與本封存索引。
