project-exchange 檔名編碼規則

格式：NN_類型碼_範圍_主題[_版本].副檔名

NN      此資料夾的閱讀／工作先後順序。
INDEX   索引。
PKG     任務或程式交付包。
HO      交接文件／handoff。
REV     審核。
DISC    討論、決策材料。
CFG     設定包。
OPS     操作手冊／前置作業。

範圍碼：
T25     Task 25。
T26-T33 Tasks 26 至 33。
T00-T33 初始任務範圍。
112-114 三個舊 Discord 伺服器範圍。

日期不放在檔名；檔案系統 metadata 與 ZIP 內部內容保留原始日期。
