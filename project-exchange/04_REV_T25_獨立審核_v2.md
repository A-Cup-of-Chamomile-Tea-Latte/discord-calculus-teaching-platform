## 五、交接包可攜性問題

交接 ZIP 排除了 `.git`，但目前 secret scanner 依賴：

```text
git ls-files
```

因此在「只拿到 ZIP、尚未建立 Git worktree」的新環境中，文件要求的：

```text
npm run check
```

可能會立即失敗。

這是 handoff portability issue，不代表原本本機 repository 有問題。建議：

- secret scanner 在 Git worktree 內維持 `git ls-files` 行為；
- 非 Git 解壓環境則使用安全的 filesystem fallback；
- 加入無 `.git` 的 regression test；
- 更新 pause handoff 說明。

- `docs/decisions/UNRESOLVED.md`
